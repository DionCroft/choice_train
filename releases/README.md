# Historical Releases

This folder preserves ChoiceTrain builds that are no longer the published GitHub Pages entry point.

The current release remains at the repository root as `index.html`, `choice_train_V1.6.0.html`, and `choice_train_V1.6.0.js`.

## Archive

| Series | Files | Notes |
| --- | --- | --- |
| V1.2 | `choice_train_V1.2.1.html` to `choice_train_V1.2.4.html` | Early standalone prototypes |
| V1.3 | Paired V1.3.0 to V1.3.2 HTML/JavaScript files | Trial schema, research foundations, and attention variants |
| V1.4 | Paired V1.4.0 to V1.4.2 HTML/JavaScript files | Teacher/Admin split, branding, themes, and panel fixes |
| V1.5 | Paired V1.5.0 HTML/JavaScript files | School-ready teacher workflow baseline |

Archived files are retained for traceability and regression investigation. They are not the recommended classroom build and do not receive fixes. Their local `assets/` copy exists only so the historical HTML snapshots can still render their original branding paths.

Use the repository-root `index.html` for current testing and deployment.
