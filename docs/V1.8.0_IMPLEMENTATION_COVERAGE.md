**Candidate:** `V1.8.0-alpha`

**Manifest:** [`V1.8.0_IMPLEMENTATION_COVERAGE.json`](V1.8.0_IMPLEMENTATION_COVERAGE.json)

**Status:** internal implementation evidence traced; external promotion evidence pending

## Purpose

This audit maps the long-horizon V1.8 objective to repository evidence. The machine-readable manifest identifies each required capability, exact runtime or document anchors, automated evidence, and an interpretation limitation. `npm run test:coverage` fails if a required objective disappears, an evidence file or anchor becomes stale, an unknown objective is inserted, or the record attempts to freeze or authorise the candidate.

The audit contains no pupil data. It does not prove educational effectiveness, transfer, neural plasticity, accessibility suitability, legal authority, research ethics approval, physical-device compatibility, EEG hardware timing, or release approval.

## External Gates

All 13 gates in [`V1.8.0_PROMOTION_EVIDENCE.json`](V1.8.0_PROMOTION_EVIDENCE.json) remain pending while the candidate is still under development:

- automated engineering evidence against the final frozen commit
- exact-head branch CI
- product-owner approval
- staff usability review
- learner safeguarding review
- information-governance review
- legal and research-ethics review
- physical Windows touchscreen, iPad Safari, Android Chrome, and Kindle Silk checks
- intended assistive-access review
- measured EEG acquisition-system timing

The implementation manifest is deliberately unable to change those statuses. Protected source evidence must remain outside the repository and only non-identifying references may be entered into the promotion record after the candidate is frozen.

## Commands

Run the coverage unit tests and evidence-anchor audit:

```bash
npm run test:coverage
```

Run the combined candidate gate:

```bash
npm run check:candidate:v180
```

Test and then generate the ignored engineering hand-off for a clean exact commit:

```bash
npm run test:review-pack
npm run build:review-pack:v180
```

The generated pack contains status codes and engineering provenance only. It does not include protected evidence or authorise any external gate.

A pass means that current repository evidence covers the declared internal objective. It does not authorise promotion. The separate `npm run check:promotion:v180` command is expected to fail until the frozen candidate has complete, reviewed external evidence and explicit approval.
