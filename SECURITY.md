# Security Policy

## Reporting a Vulnerability

Please do not report security or privacy vulnerabilities through a public GitHub issue, especially if the report could contain pupil information.

Use GitHub's private vulnerability reporting for this repository where available, or contact the repository owner privately through the organisation's agreed channel. Include the affected version, reproduction steps using synthetic data, likely impact, and any suggested mitigation.

## Supported Version

Security fixes are applied to the current published release. Historical files under `releases/` are retained for traceability and are not supported classroom builds.

## Sensitive Data

Never attach real pupil photographs, names, context notes, exported sessions, EEG recordings, or school credentials to an issue, pull request, or test fixture.
